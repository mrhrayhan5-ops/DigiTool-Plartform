## 📌 About The Project

**DigiTools** is a responsive e-commerce digital product storefront. Built with React and styled using Tailwind CSS and DaisyUI, it delivers a smooth single-page shopping experience where users can seamlessly browse digital goods, track cart updates in real time, and process orders.

---

## ✨ Key Features

* 🛒 **Dynamic Cart Management**  
  Add digital products to your cart with instant total price calculations, deduplication checks, and single-click item removal.

* 🔔 **Navbar-to-Cart Sync & Badge Counter**  
  A live cart badge in the top navigation bar updates as items are added, seamlessly scrolling down and switching tabs to the cart view when clicked.

* 📱 **Responsive Tab UI**  
  Switch between product listings and cart views using clean DaisyUI tab navigation with zero page reloads.
